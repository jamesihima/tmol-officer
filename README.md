# TMO Officer App

Static app — upload the contents of this folder to a GitHub repo and enable GitHub Pages (Settings → Pages → Deploy from branch → main / root). Open index.html.

- On phones (or any screen under 600px wide) the app fills the screen with no device frame. Add `?device=1` to the URL to force full-screen on desktop.
- Data is stored in the browser (localStorage). Apps hosted under the same domain (e.g. all as project sites on yourname.github.io) share data on the same device/browser. Different phones are not connected without a real backend.
- Testing mode: any 6-digit OTP works; PINs are whatever you set.
